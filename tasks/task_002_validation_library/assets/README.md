# Assets - Task 002: Validation Library

## Required Assets

### Validation Icons
**Files needed:**
- `check-mark.svg` - Success/valid state icon
- `error-icon.svg` - Error/invalid state icon
- `warning-icon.svg` - Warning state icon

**Purpose:** Visual indicators for validation states

### Form Assets
**Files needed:**
- `input-bg.svg` - Background for form inputs
- `focus-ring.svg` - Focus state ring for inputs

**Purpose:** Form input styling

## Directory Structure
```
assets/
├── icons/
│   ├── check-mark.svg
│   ├── error-icon.svg
```

## Notes
- Icons must be accessible (proper contrast)
- SVG icons should scale well on mobile
- Form assets should support light/dark themes
