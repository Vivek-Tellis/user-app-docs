# Assets - Task 003: Authentication Core

## Required Assets

### Brand Assets
**Files needed:**
- `logo.svg` - App logo
- `brand-name.svg` - Brand text/logo
- `icon.png` - App icon (64x64)

### Authentication Icons
**Files needed:**
- `phone-icon.svg` - Phone input icon
- `otp-icon.svg` - OTP verification icon
- `success-icon.svg` - Success checkmark
- `shield-icon.svg` - Security/privacy icon

### Background Assets
**Files needed:**
- `auth-background.svg` - Background pattern or gradient
- `hero-illustration.svg` - Main illustration for login screen

## Directory Structure
```
assets/
├── brand/
│   ├── logo.svg
│   ├── brand-name.svg
│   └── icon.png
├── icons/
│   ├── phone-icon.svg
│   ├── otp-icon.svg
│   ├── success-icon.svg
│   └── shield-icon.svg
└── illustrations/
    ├── auth-background.svg
    └── hero-illustration.svg
```

## Notes
- Logo should work on both light and dark backgrounds
- Icons must be accessible (proper contrast ratios)
- Illustrations should be lightweight (optimized SVGs)
- Use consistent color palette from DESIGN_SYSTEM.md
